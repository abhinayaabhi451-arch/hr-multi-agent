To Run the Porject Following Steps need to follow:

Step 1: Create .env file
Step 2: Add Gemini API key in .env
        Ex:  GOOGLE_API_KEY="Paste your key here"

Step 3: Install dependencies
pip install langchain langchain-google-genai python-dotenv
pip show langchain-google-genai

Step 4: run follwoing command to create and activate virtual environment
python -m venv venv
venv\Scripts\activate

Step 5: run program 
python main.py
